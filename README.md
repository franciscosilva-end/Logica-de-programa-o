# Lógica de Programação com VisualG

Este repositório contém projetos e exercícios desenvolvidos com o objetivo de praticar e consolidar fundamentos de lógica de programação utilizando o VisualG.

Aqui estão reunidos desde problemas básicos até aplicações um pouco mais estruturadas, demonstrando evolução no raciocínio lógico e na organização de código.

Comecei com programas simples e estou evoluindo para projetos mais complexos.

## Objetivo

Desenvolver uma base sólida em programação, focando em:

* Raciocínio lógico
* Resolução de problemas
* Estruturas fundamentais da programação
* Organização de código

## Estrutura do Repositório

```bash
projetos-basicos/
projetos-intermediarios/
docs/
```

## Projetos

### Projetos Básicos

Local: `projetos-basicos/`

* **Área de Retângulo**

  * Cálculo de área com base e altura
  * Introdução a variáveis e entrada de dados

* **Calculadora Simples**

  * Operações matemáticas básicas
  * Uso de estruturas condicionais

### Projetos Intermediários

Local: `projetos-intermediarios/`

* **Quiz de Programação**

  * Perguntas e respostas
  * Sistema de pontuação
  * Feedback ao usuário
  * Estruturas condicionais aplicadas

##  Utilizadas
